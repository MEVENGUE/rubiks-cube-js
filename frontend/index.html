Sources d’inspiration

Rubik Graph n’est pas une copie d’un dépôt unique : il réécrit en JavaScript plusieurs idées (geste, graphe, solveur, robot) et s’appuie sur des bibliothèques open source.

Applications et démos

  • Gesture-Recognition-for-Rubik’s-Cube — main gauche = orbite, main droite = viser + pincer.
  • Représentation 2D en cercles · version plus fluide — orbites U / F / R, stickers aux intersections.
  • Hobby Rubik’s Cube Circles 2D Projection — le GIF Reddit comme graphe de facettes sur des cercles.
  • Dexterous Cube Solving (Yanjie Ze) — bras qui tient le cube et rejoue la solution.

Mathématiques et algorithmes

  • Solving a Rubik’s Cube Using Graph Theory (Ric Donati) — graphe de Cayley, chemin vers l’identité.
  • Cayley graphs & God’s algorithm — distance dans le graphe = longueur de solution.
  • Herbert Kociemba — Two-Phase Algorithm · détail mathématique — solveur réel (~20 coups).
  • David Singmaster, Notes on Rubik’s Magic Cube — notation U R F D L B et suffixes ' / 2.

Bibliothèques

  • cubejs (npm, paquet, auteur original akheron) — modèle 3×3 et solveur Kociemba JS.
  • Three.js — OrbitControls, RoundedBoxGeometry.
  • MediaPipe Hand Landmarker — @mediapipe/tasks-vision.
  • Vite — bundler, HMR et worker.
